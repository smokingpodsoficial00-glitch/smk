# 🧠 Instruções de Inicialização do Agente - Smoking Pods

Sempre que um novo chat de trabalho for iniciado neste workspace:

1. **Leitura de Contexto e Navegação Semântica Obrigatória no Obsidian**:
   - Leia imediatamente o arquivo [00 - Alimentação de Dados e Atualizações.md](file:///D:/Obsidian%20Vaults/Cerebro%20Smoking%20Pods/03_Status/00%20-%20Alimenta%C3%A7%C3%A3o%20de%20Dados%20e%20Atualiza%C3%A7%C3%B5es.md).
   - **Busca Semântica Contínua**: Em qualquer nova conversa ou ao abordar qualquer tema específico (CRM, Retenção, Estoque, Fornecedores, WhatsApp, Frete, Copywriting, Marketing), pesquise e leia proativamente as notas correspondentes no Obsidian (`D:/Obsidian Vaults/Cerebro Smoking Pods/`) para resgatar 100% das decisões prévias, regras consolidadas e contexto histórico antes de formular respostas ou planos.

2. **Verificação de Atualizações Pendentes**:
   - Verifique a existência de notas na pasta [00_Entrada/](file:///D:/Obsidian%20Vaults/Cerebro%20Smoking%20Pods/00_Entrada).
   - Se houver novos arquivos de log de auditoria, consolide as alterações de regras de frete, bypass e WhatsApp conforme as regras de curadoria do vault e exclua os arquivos lidos.

3. **Curadoria do Vault**:
   - Siga rigorosamente as regras definidas em [AGENTS.md](file:///D:/Obsidian%20Vaults/Cerebro%20Smoking%20Pods/99_Sistema/AGENTS.md).

4. **Regra de Trabalho em Equipe (Git Sync Automático)**:
   - Toda vez que for iniciada uma nova tarefa ou recurso neste workspace, execute primeiro um `git pull` para baixar as novidades do parceiro.
   - Toda vez que uma tarefa for concluída com sucesso, execute automaticamente um `git push` para sincronizar e enviar as alterações para a equipe.

5. **🔒 Regra Absoluta de Estoque e Mercadorias**:
   - Conforme [.agents/rules/gestao_estoque_exclusiva.md](file:///D:/projetosss/smoking-pods/.agents/rules/gestao_estoque_exclusiva.md), o robô de IA / Chatbot e scripts automáticos têm proibição estrita de alterar, cadastrar ou deletar qualquer sabor, modelo ou estoque. A gestão é 100% exclusiva dos administradores humanos via Painel Admin.
